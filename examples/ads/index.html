Preroll ad example

The same skippable preroll, loaded three ways. Pick the one that matches your page.

  • Player from a CDN — two type="module" tags, no build step for the player. Reach for this when you have no bundler.
  • One ES module — a single file you host yourself. Fewest requests while staying an ES module.
  • One classic script — a plain <script> with no type="module". For pages that cannot use modules at all.

Add ?ad=image-preroll to any of them to run the image ad instead of the video one. Both media types use the same overlay.

The pages load from ./dist/, which the ads package build generates. If they come up blank, build it first — see the README.

For what you can set on the player and what you can call on it, see Configure and control the player.
