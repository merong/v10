프리롤 광고 실행하기

Video.js 10 플레이어에 광고를 붙이는 데 필요한 것은 엘리먼트 하나뿐, JavaScript는 없습니다.

마크업

<link rel="stylesheet" href="/video-ads.css" />
<script defer src="/video-ads.iife.js"></script>

<video-player>
  <video-skin>
    <video src="/video.mp4" playsinline></video>
    <media-ads src="/ads.json"></media-ads>
  </video-skin>
</video-player>

연동은 이것이 전부입니다. <media-ads>는 컨텍스트로 플레이어를 찾고, 광고 목록을 받아오고, 시청자의 첫 재생을 기다렸다가 광고를 실행한 뒤 재생권을 본편에 돌려줍니다.

소스가 반드시 마크업에 있어야 하는 것은 아닙니다. 광고 여부를 나중에 정하는 페이지는 답이 오는 시점에 src를 설정하면 됩니다 — 그때 본편이 이미 재생 중이라면 광고가 곧바로 시작됩니다.

이 엘리먼트는 놓인 자리에 아무것도 그리지 않으므로, 스킨의 자식들 중 어디에 두든 상관없습니다. 플레이어 스토어에 더하는 것도 없습니다. 덕분에 광고 기능을 넣어 빌드한 플레이어가 아니라 어떤 v10 플레이어에든 그대로 얹을 수 있습니다.

어떤 파일을 불러올까

불러올 파일은 세 가지 — 플레이어와 광고를 함께 담은 video-ads.iife.js와 video-ads.js, 광고만 담은 videojs-ads.js — 이고, 어느 것을 쓰든 오버레이 스타일을 담은 video-ads.css와 짝지으면 됩니다.

선택 기준과 설치 절차, defer와 스크립트 순서처럼 방식마다 지켜야 할 조건은 설치 가이드에 정리되어 있습니다.

광고 데이터

src가 가리키는 JSON의 형태입니다.

{
  "ads": [
    {
      "id": "video-preroll",
      "type": "video",
      "src": "/media/ad.mp4",
      "mime": "video/mp4",
      "duration": 10,
      "skipAfter": 3,
      "clickUrl": "https://example.com",
      "trackingUrl": "/api/ad-events"
    }
  ]
}

목록의 첫 항목이 실행됩니다.

필드 필수 의미
id예여러분의 식별자. 트래킹 이벤트에 함께 보고됩니다.
type예video 또는 image.
src예광고 미디어의 URL.
mime예그 미디어의 콘텐츠 타입.
duration예광고가 재생되는 초.
skipAfter예건너뛰기 버튼이 활성화되기까지의 초. 0이면 즉시 건너뛸 수 있습니다.
clickUrl아니오광고를 클릭하면 새 탭에서 엽니다.
trackingUrl아니오아래 비콘을 받을 엔드포인트. 생략하면 비콘을 보내지 않습니다.
포맷 type 렌더링
MP4, WebMvideo<video>, 자동 재생
WebP, GIFimage<img>, duration 동안 유지

형식이 잘못된 항목은 버려지고, 요청이 실패하면 빈 목록이 됩니다 — 어느 쪽이든 예정된 광고가 없었던 것처럼 본편이 재생됩니다. 광고 서버 장애가 재생을 막는 일은 없습니다.

속성

속성 기본값 효과
src—광고 목록을 받아올 위치. 없으면 엘리먼트는 아무 일도 하지 않습니다. 재생이 시작된 뒤를 포함해 언제든 설정할 수 있습니다.
skip-labelSkip ad건너뛰기가 가능해진 뒤의 버튼 문구.
skip-countdown-labelSkip in {seconds}s그 전까지의 버튼 문구.
timer-labelAD {elapsed} / {duration}좌측 하단 표시.
media-altAdvertisement이미지 광고의 alt.
tick-interval250카운트다운 갱신 주기(밀리초).
max-wait5duration을 넘겨 광고를 포기하기까지 허용하는 추가 실시간 초.
 
<media-ads
  src="/ads.json"
  skip-label="광고 건너뛰기"
  skip-countdown-label="{seconds}초 후 건너뛰기"
  timer-label="광고 {elapsed} / {duration}"
></media-ads>

속성은 함수를 담을 수 없으므로 카운트다운과 타이머는 템플릿을 받습니다. {seconds}, {elapsed}, {duration}이 숫자가 들어갈 자리를 표시합니다. 숫자의 위치는 언어마다 다르며, 접두사와 접미사가 아니라 템플릿인 이유가 그것입니다.

이 라벨들은 플레이어의 번역 레지스트리를 거치지 않습니다. 오버레이는 플레이어의 로케일에서 해석되는 대신 직접 구성되므로, 원하는 문자열을 그대로 넘기면 됩니다.

오버레이 스타일링

오버레이는 light DOM에 있으므로 여러분의 스타일시트가 닿습니다 — video-ads.css 뒤에 불러와 덮어쓰세요.

클래스 엘리먼트
.vjs-ads-overlay루트. z-index: 100으로 플레이어를 덮습니다
.vjs-ads-media광고의 비디오 또는 이미지. object-fit: contain
.vjs-ads-timer좌측 하단 표시
.vjs-ads-skip우측 하단 버튼

상태는 data 속성에 실리므로, 클래스를 토글하지 않아도 스타일이 상태를 따라갑니다.

셀렉터 적용 시점
.vjs-ads-overlay[data-ad-phase="playing"]광고가 표시 중
.vjs-ads-overlay[data-ad-phase="hidden"]광고 없음
.vjs-ads-skip[data-skip-available="true"]건너뛰기 가능
.vjs-ads-skip[data-skip-available="false"]아직 카운트다운 중
 
.vjs-ads-skip {
  background: rgb(255 200 0 / 0.9);
  color: #000;
  border: none;
  border-radius: 8px;
}

.vjs-ads-skip[data-skip-available="true"]:hover {
  background: rgb(255 220 50);
}

트래킹

광고에 trackingUrl이 있으면 오버레이가 아래 각 시점에 작은 JSON 본문을 POST 합니다. 없으면 아무것도 보내지 않습니다.

이벤트 발생 시점
impression광고가 시작될 때
click시청자가 광고를 클릭할 때
skip시청자가 건너뛸 때
complete광고가 duration에 도달할 때
error광고 미디어의 로드나 재생이 실패할 때

비콘은 keepalive를 쓰므로, 클릭으로 페이지를 떠나도 보고는 남습니다.

직접 제어하기

미드롤, 시청자별로 고른 광고, 직접 짠 스케줄링처럼 이 엘리먼트의 생명주기가 맞지 않을 때는, 같은 번들이 그것을 이루는 조각들을 그대로 내보냅니다.

export 역할
fetchAds(url, signal?)목록을 읽고 형식이 잘못된 항목을 버립니다. 실패하면 []로 resolve 합니다.
AdsOverlay광고를 그립니다: 미디어, 타이머, 건너뛰기 버튼.
trackAdEvent(url, event)비콘 하나를 보냅니다.
 
import { AdsOverlay, fetchAds } from '/video-ads.js';

const overlay = new AdsOverlay(container, {
  labels: { skipCountdown: (seconds) => `${seconds}초 후 건너뛰기` },
});

직접 생성할 때는 라벨을 템플릿이 아니라 함수로 받습니다. 넘기는 컨테이너는 위치 기준(positioning context)을 만들어야 하며, 엘리먼트를 쓸 때는 그 준비를 대신 해줍니다.

문제 해결

컨트롤은 그려지는데 아무것도 반응하지 않습니다

플레이어가 미디어에 붙지 못한 것입니다. 클래식 스크립트라면 앞서 설명한 defer 누락입니다. document.querySelector('video-player').store.target으로 확인하세요 — 붙지 않았다면 null입니다.

광고 없이 본편만 재생됩니다

의도된 동작입니다. 네트워크 탭에서 src 요청을 확인하세요. 요청 실패, 잘못된 JSON, 필수 필드가 빠진 항목은 모두 빈 목록으로 귀결되고, 빈 목록은 광고 없음을 뜻합니다.

오버레이가 다른 요소에 가립니다

오버레이는 스킨 안에서 z-index: 100에 놓입니다. 플레이어가 아니라 여러분 쪽 오버레이 요소에 더 큰 z-index가 있는지 살펴보세요.

광고가 duration을 넘겨 계속됩니다

백그라운드 탭에서는 브라우저가 카운트다운을 떠받치는 실시간 타이머를 조절(throttle)하므로, 자체 재생 진행이 없는 광고는 늦게 끝납니다. 재생 중인 비디오 광고는 영향을 받지 않습니다. 여기서 tick-interval은 도움이 되지 않습니다 — 간격을 얼마로 요청하든 조절이 적용되기 때문입니다.

광고가 끝나지 않습니다

일어날 수 없는 일입니다. 광고 미디어가 아무것도 보고하지 않아도 실시간 시계가 duration 더하기 max-wait에서 광고를 끝내고, 미디어 오류는 즉시 끝냅니다. 그런데도 겪는다면 두 가지가 모두 포함된 빌드를 불러오고 있는지 확인하세요 — 이전 빌드는 timeupdate만으로 카운트다운을 굴렸고, 닿지 않는 광고 URL이 본편을 무한정 붙잡았습니다.
